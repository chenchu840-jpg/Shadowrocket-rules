## 📝 使用方法

### 在 Shadowrocket 中导入规则

1. 打开 Shadowrocket 应用
2. 选择 "配置" → "规则" → "+"
3. **推荐复制 Raw 链接**（最快）
4. 粘贴到 URL 输入框
5. 点击确认下载

### 选择规则建议

- **日常使用**: 推荐使用 `apple.list` + `google.list`
- **工作学习**: 添加 `Microsoft.list` + `WPS.list`
- **社交媒体**: 添加 `wechat.list` + `tiktok.list`
- **金融服务**: 添加 `WISE.list` + `OCBC.list` + `IBKR.list`
